# Home Item Visualizer — הדמיית עיצוב הבית

אפליקציית ווב עצמאית: מעלים תמונה של הבית ותמונה של פריט (קרמיקה, ריצוף,
גדר, דלת וכל דבר אחר) — והמערכת יוצרת הדמיה פוטוריאליסטית שממזגת את הפריט
המדויק (אותו צבע, מרקם ודוגמה) לתוך תמונת הבית, עם תאורה ופרספקטיבה תואמות.

המערכת משתמשת במודל עריכת התמונות של גוגל, `gemini-2.5-flash-image`
("Nano Banana"), שמיועד בדיוק למשימה הזו — עריכת תמונה תוך שילוב אובייקט
אמיתי מתמונה נוספת.

## התקנה

```bash
cd home_visualizer
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

ערכו את `.env` והכניסו מפתח API של Gemini (חינמי, מתקבל ב-
https://aistudio.google.com/apikey):

```
GEMINI_API_KEY=your_key_here
```

## הרצה

```bash
python app.py
```

השרת יעלה בכתובת http://localhost:5050

## שימוש

1. העלו תמונה של הבית/הקיר/החדר.
2. העלו תמונה ברורה של הפריט שברצונכם להוסיף (למשל תמונת מוצר של קרמיקה
   מהאתר של החנות).
3. תארו במילה-שתיים מה הפריט (למשל "קרמיקה לחיפוי קיר חוץ").
4. אופציונלי: הוסיפו הנחיית מיקום (למשל "לחפות את הקיר מתחת לחלונות").
5. לחצו "צור הדמיה" — תוך כ-10-20 שניות תתקבל תמונה משולבת שניתן להוריד.

## הערות

- קבצי ההעלאה נשמרים זמנית בלבד ונמחקים מיד לאחר היצירה.
- תמונות התוצאה נשמרות תחת `static/results/` (לא עולות ל-git).
- גודל קובץ מקסימלי להעלאה: 12MB לתמונה.
- פורמטים נתמכים: PNG, JPG, WEBP.
