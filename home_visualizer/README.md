# Home Item Visualizer — הדמיית עיצוב הבית

אפליקציית ווב עצמאית: מעלים תמונה של הבית ותמונה של פריט (קרמיקה, ריצוף,
גדר, דלת וכל דבר אחר) — והמערכת ממזגת את הפריט המדויק (אותו צבע, מרקם
ודוגמה) לתוך תמונת הבית, ומאפשרת להוריד את התוצאה.

יש שני מצבי עבודה:

1. **עריכה ידנית (ברירת המחדל)** — עובדת **מיד, לגמרי בדפדפן, בלי שום
   מפתח API ובלי עלות**. גוררים, משנים גודל, מסובבים ומרצפים את הפריט
   מעל תמונת הבית, עם שליטה בשקיפות ובמצב מיזוג (Blend), ומורידים תמונה
   מוכנה.
2. **יצירה אוטומטית ב-AI (אופציונלי)** — שולח את שתי התמונות למודל עריכת
   התמונות של גוגל, `gemini-2.5-flash-image` ("Nano Banana"), שיוצר הדמיה
   פוטוריאליסטית לגמרי אוטומטית (תאורה, פרספקטיבה וצללים מותאמים). דורש
   מפתח `GEMINI_API_KEY`. אפשר להוסיף את זה בהמשך — האתר עובד גם בלעדיו.

## התקנה

```bash
cd home_visualizer
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

המצב הידני עובד ישר, בלי לגעת ב-`.env`. אם בהמשך תרצו גם את מצב ה-AI,
ערכו את `.env` והכניסו מפתח API של Gemini (יש רמה חינמית, מתקבל ב-
https://aistudio.google.com/apikey):

```
GEMINI_API_KEY=your_key_here
```

## הרצה

```bash
python app.py
```

השרת יעלה בכתובת http://localhost:5050

## שימוש — מצב ידני (ברירת מחדל, בלי API)

1. העלו תמונה של הבית/הקיר/החדר.
2. העלו תמונה ברורה של הפריט (למשל תמונת מוצר של קרמיקה מהאתר של החנות).
3. גררו את הפריט כדי למקם אותו, גררו את הנקודה בפינה כדי לשנות גודל,
   ואת הנקודה הירוקה למעלה כדי לסובב.
4. אם מדובר בקרמיקה/ריצוף שצריך לכסות שטח — סמנו "ריצוף חוזר" והתאימו
   את גודל האריח.
5. כווננו שקיפות ומצב מיזוג (מומלץ להתחיל מ-Multiply) כדי שהפריט ייראה
   משולב יותר בתאורת התמונה.
6. לחצו "הורדת התמונה".

## שימוש — מצב AI (אופציונלי, דורש מפתח)

1. עברו לטאב "יצירה אוטומטית ב-AI".
2. העלו את שתי התמונות, תארו את הפריט והוסיפו הנחיות מיקום (אופציונלי).
3. לחצו "צור הדמיה עם AI" — תוך כ-10-20 שניות תתקבל תמונה משולבת אוטומטית.

## הערות

- מצב ה-AI: קבצי ההעלאה נשמרים זמנית בלבד ונמחקים מיד לאחר היצירה;
  תמונות התוצאה נשמרות תחת `static/results/` (לא עולות ל-git).
- מצב ידני: הכל קורה בדפדפן — שום תמונה לא נשלחת לשרת.
- גודל קובץ מקסימלי להעלאה (מצב AI): 12MB לתמונה.
- פורמטים נתמכים: PNG, JPG, WEBP.
